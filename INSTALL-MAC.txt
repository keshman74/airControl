airCloudCTRL v3.0 — clean install on macOS

1. Unzip the archive to a NEW folder. Do not copy it over the old v2.0 folder.
2. Open Terminal.
3. Go to the new project folder, for example:
   cd "/Users/lab/AI/airCloudCTRL GPT/airCloudCTRL v3.0"
4. Install dependencies once:
   npm install
5. Start the app:
   npm run dev
