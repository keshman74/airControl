# airControl Mobile

Одна кодовая база React для iOS и Android. Capacitor предоставляет системный HTTP-транспорт. Общий клиент использует Linkplay HTTPAPI и UPnP PlayQueue из канонической KB.

## Первый сценарий

На телефоне в одной сети с Office 29 откройте приложение, оставьте `192.168.0.29` и нажмите **Подключить**. Для другого локального IPv4-устройства введите его адрес. Клиент проверяет UUID и прошивку из `getStatusEx`, ищет описание UPnP на известных портах и читает объявленный SCPD перед первым BrowseQueue.

- **Сейчас играет** показывает CurrentQueue. Подсветка активного трека включается при стабильном состоянии воспроизведения, для проверенных источников USB/Qobuz и индекса в диапазоне.
- **USB** читает USBDiskQueue независимо от текущего источника. Если отдельное DIDL Metadata повреждено, строка остаётся видимой с именем файла, когда оно доступно.
- **Очереди** показывает каталог TotalQueue и его активную запись.
- **Обновить** перечитывает состояние и выбранную очередь. Обложки показываются по абсолютным HTTPS-адресам.

Первый выпуск выполняет запросы чтения. Статусы протоколов других семейств и HTTPS-устройства с клиентскими сертификатами требуют отдельных адаптеров и проверки.

## Сборка

Из папки проекта:

```bash
npm ci
npm run sync
```

### iOS

```bash
npm run ios
```

В Xcode откройте схему **App**, выберите свою команду в **Signing & Capabilities**, подключите iPhone и нажмите Run. Разрешите приложению доступ к локальной сети. Приложение использует системный HTTP для частных IPv4-адресов.

### Android

```bash
npm run android
```

Откройте проект в Android Studio с установленной Android SDK Platform 36. Дождитесь Gradle Sync, выберите Android-телефон и нажмите Run. В манифесте приложения включён локальный HTTP. Общий клиент принимает только частные IPv4 и отклоняет UPnP-адреса другого хоста.

После изменения общих исходников выполняйте `npm run sync`, чтобы обновить файлы для обеих платформ.
