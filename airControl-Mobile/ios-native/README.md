# airControl iOS · нативная сборка на Linkplay Music Kit

Основной проект для дальнейшей разработки airControl на iPhone. Он собран на основе сохранённого Xcode-демо Linkplay Music Kit 1.0.14. Навигация и структура ориентированы на WiiM Home. Оформление и название принадлежат airControl. Android-перенос ведётся отдельно в `../android-port/`; React + Capacitor прототип и его сетевые наработки сохранены в `../src/`.

## Что реализовано

| Экран | Реализация |
|---|---|
| Устройства | SDK discovery и события online/offline. Выбор устройства по UUID, отображение IP и прошивки. Повторное обнаружение свайпом вниз. |
| Сейчас играет | Метаданные SDK, HTTPS-обложка, play/pause, предыдущий/следующий трек, громкость и позиция. Команды отправляются выбранному устройству при действии пользователя. |
| Обзор | Чтение CurrentQueue, USBDiskQueue и TotalQueue через SDK. USB-строка сохраняется при ошибке вложенного DIDL; для локального пути можно показать имя файла. |
| Активный трек | Для Office 29 с прошивкой 4.6.415156 и очередью USB или Qobuz применяется подтверждённый one-based LastPlayIndex с проверкой диапазона. Для остальных устройств подсветка индекса требует отдельной проверки. |
| Пресеты, NAS, медиатека iPhone, Multiroom и будильники | Подключены соответствующие экраны SDK-демо. Доступность функций зависит от устройства и состояния SDK. |
| Настройки | Выбор из объявленных устройством источников, просмотр полей EQ и таймер сна. |
| Deezer | Вход и чтение сессии выбирают источник по метаданным модели: A98 использует `Deezer2`, A31 — старый `Deezer`. Перед SOAP-запросом приложение читает UPnP description/SCPD выбранной колонки, находит объявленный PlayQueue `controlURL` и проверяет наличие действия; фиксированный порт и controlURL не предполагаются. `UserLogin` ждёт до 35 секунд, SOAP Fault с HTTP 500 сохраняется для разбора. Каталог Airable содержит библиотеку, поиск и переходы по страницам. Для новых устройств очередь формируется через `LPMDPKitManager` с источником `Deezer2` и передаётся `LPDevicePlayer.playAudioWithMusicDictionary`; при отказе SDK или отсутствии данных аккаунта остаётся совместимый PlayQueue-путь `CreateQueue` + `PlayQueueWithIndex`. |

Пароль Deezer вводится в приложении и передаётся только выбранной колонке; airControl не сохраняет его на диске. Подпись каталога строится по сессионным данным самой колонки, поэтому Deezer App ID и OAuth-регистрация не нужны. Реализация `Deezer2` реконструирована по WiiM Home 3.6.10 (APK SHA-256 `99ebfac7f76ecb6c33b6988ab8ca11bb0833e22329e323f7299546cdc5da490a`) и сверяется с iOS SDK DPMKit API. Новая сборка с чтением PlayQueue description/SCPD установлена на iPhone; успешный вход и воспроизведение на A98 ожидают повторной аппаратной проверки. Каталоги/аккаунты Qobuz и TIDAL, RoomFit, редактирование очереди и настройка новых устройств остаются отдельными задачами. Результаты чтения из KB относятся к прямому UPnP; соответствие всех вызовов SDK сетевым запросам требует проверки.

## Сборка и запуск

Откройте `LPMusicKitDemo.xcodeproj`, выберите схему `LPMusicKitDemo` и физический iPhone. Для подписи используется команда проекта, а идентификатор приложения — `com.filmoscopelab.aircontrol.native`. В рабочей копии удалены два приватных импорта из AFNetworking и отключён Access Wi‑Fi Information для Personal Team. При первом старте разрешите доступ к локальной сети. На вкладке «Устройства» выберите Office 29.

Первый аппаратный прогон начинается с обнаружения Office 29 через SDK. Затем откройте «Сейчас играет» и «Обзор», проверьте текущую очередь, USB и каталог очередей. При смене трека USB или Qobuz обновите текущую очередь и сравните подсветку с плеером. У парсера есть поддержка обоих вариантов `QueueContext`: вложенного XML и экранированного XML-текста. Некорректный `LastPlayIndex` пропускается, а резервное имя USB-файла декодируется из URL.

## Правило для обложек радиостанций

Каждая строка резервирует область 44 × 44 pt для обложки и заглушки. Изображение вписывается с сохранением пропорций. Разрешение, соотношение сторон и завершение загрузки картинки не меняют размер области, отступ текста или высоту строки. Высота может меняться с размером текста в настройках доступности iOS.
