airControl v4.0.4 — installer builds

macOS Apple Silicon (ARM64) DMG:
  npm install
  npm run dist:mac:arm64

macOS Intel x64 DMG:
  npm install
  npm run dist:mac:x64

Windows x64 NSIS EXE:
  npm install
  npm run dist:win:x64

Windows ARM64 NSIS EXE:
  npm install
  npm run dist:win:arm64

Both Windows architectures:
  npm install
  npm run dist:win

Stable installer identity:
  appId = com.filmoscopelab.aircontrol
  productName = airControl

Windows installer is per-user (perMachine=false, allowElevation=false).
Icons:
  macOS: build/icon.icns
  Windows: build/icon.ico

Do NOT run npm audit fix --force.
